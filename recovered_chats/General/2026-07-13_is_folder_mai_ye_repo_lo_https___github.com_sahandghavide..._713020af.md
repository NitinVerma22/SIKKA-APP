### 🤖 Assistant

Vercel par in GitHub repositories ko live (deploy) karna bahut aasan hai, kyunki yeh simple HTML/CSS/JS projects hain. Inhe deploy karne ke liye koi command run karne ki zaroorat nahi hai, aapko bas Vercel ki website se connect karna hai.

Niche diye gaye steps ko follow karein:

**Step 1: Vercel par Login karein**
1. Apne browser mein [Vercel ki website (vercel.com)](https://vercel.com/) par jayein.
2. **"Sign Up"** ya **"Login"** par click karein aur apna **GitHub account** select karein. (Isse Vercel directly aapke GitHub repos read kar payega).

**Step 2: Project Import karein**
1. Login hone ke baad Dashboard par aapko **"Add New..."** ka button dikhega, uspar click karke **"Project"** select karein.
2. Wahan "Import Git Repository" ka option aayega, jahan aapko apni GitHub ki repositories dikhengi (agar nahi dikhti toh "Adjust GitHub App Permissions" par click karke Vercel ko permission de dein).
3. Aapke project (jaise `button-ripple-effect`) ke saamne ek **"Import"** button hoga, uspar click karein.

**Step 3: Deploy karein**
1. Import par click karne ke baad ek naya page khulega jahan aapse Project Name aur Build settings poochi jayengi. 
2. Kyunki aapke projects bilkul simple HTML/CSS/JS hain, aapko **koi setting change karne ki zaroorat nahi hai**. (Framework Preset apne aap 'Other' rahega).
3. Seedhe niche ja kar blue color ke **"Deploy"** button par click kar dein.

**Step 4: Live Link lein**
- Vercel kuch hi seconds mein aapka project deploy kar dega aur aapko ek screen par "Congratulations!" dikhega.
- Wahan aapko aapke live project ka URL mil jayega (jaise `button-ripple-effect-abcdef.vercel.app`), jise aap apne resume ya portfolio mein add kar sakte hain.

Aapko yahi same steps baaki dono projects (`dark-mode-toggle` aur `profile-statistics`) ke liye bhi repeat karne honge. Agar koi error aaye ya kuch samajh na aaye, toh mujhe batayein!
